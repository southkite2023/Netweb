# 统一选择页固定订阅链接

主流程使用 /api/calendar/v1/selection.ics?s=...，选择参数以固定规范编码，包含游戏项目/类型/格式/持续设置及Anime AniList ID；不含临时文件地址。相同选择得到同一URL。更改网页选择不会修改旧订阅，需替换链接。

动漫调用现有受限上游缓存与自动生成源，保留UID、SEQUENCE、取消状态；中文标题按本站目录替换，动漫移除推测持续区间。尚未映射自动源的条目明确阻止生成，避免静态快照冒充自动数据。游戏每次读取站点当前events.json，公告数据维护更新后无需重新订阅，但游戏自动采集尚未实现。

后台代码无新增依赖和迁移，独立备份后仅替换calendar-feed.js及新增selection-feed.js、selection-calendar.js，保持原双语动漫接口兼容。前端发布仍仅包含静态文件。

测试覆盖同链接新集数、新游戏日期、稳定UID、缓存ETag、503保留行为、未知ID及恶意参数。客户端实际刷新周期由日历应用决定。

原神卡池补齐：7.1下半三个卡池的开放区间与结束提醒，7.2上半角色/武器池的开启日期与精确结束提醒。7.2开启钟点未知，不能以维护开始时间代替。弹窗列出已收录的事件类型。
