# 星账账号参数云存储

2026-10-29：星账 3.2.0 主动保存单个余额账户时，将完整查询参数上传到 Yuashie 登录账号，包括服务商、名称、API Key/Secret、AccessKey ID、接口/订阅地址、余额字段路径、币种与分类。上传成功后写入本机副本。失败时保留原本机参数并提示重试。历史账户仅在用户主动重新保存时上传，不批量迁移，不在此版本自动填充。

存储位置：现有 Yuashie PostgreSQL 数据库的 `astracct_parameters` 表，复合主键 `(user_id, account_id)`。参数整体 AES-256-GCM 加密，AAD 绑定用户、记录及格式版本；独立随机密钥配置在 API 服务私有环境文件 `ASTRACCT_PARAMETERS_KEY`，格式为 64 位十六进制，不能写入仓库、输出到日志或与数据库备份混放。保留密钥以恢复备份；不可直接替换密钥，后续轮换必须迁移数据。

接口：`POST /api/astracct/parameters` 接收 `{version:1,parameters:{...}}`；GET 返回当前账号参数，供后续自动填充；DELETE `/:id` 删除当前账号单项。账号从服务端现有登录会话确定，沿用 Origin/CSRF/Bearer 验证。响应禁用缓存，限制字段与体积，不请求用户提供的接口地址。密钥未配置返回 503，禁止降级明文存储。

本机删除暂不关联云端删除；云端 DELETE 已预留。不同设备编辑同一记录时最后一次保存生效；本机写入失败也不会撤销已成功写入云端的副本。账户注销时通过外键级联删除参数。

部署：先备份，在现有发布锁内添加 `010_astracct_parameters.sql`，配置独立密钥，部署模块并注册到 API，重启后检查未认证请求为 401。验证后再发布依赖此接口的客户端。
